# Financial Reconciliation System

This project implements a financial reconciliation system that matches platform transactions with bank settlements and identifies discrepancies.

## Features
- Synthetic data generation with real-world anomalies
- Detection of missing, duplicate, and orphan records
- Rounding mismatch and delayed settlement detection
- Automated validation test suite
- Structured reconciliation report generation

## Files Included
- main.py → Core implementation
- transactions.csv → Transaction dataset
- settlements.csv → Settlement dataset
- discrepancy_log.csv → Detected issues
- reconciliation_report.json → Final report
- financial_reconciliation_report.docx → Detailed documentation

## How to Run
1. Run main.py in Python/Jupyter
2. Outputs will be generated in the outputs folder
